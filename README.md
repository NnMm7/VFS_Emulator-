VFS Emulator (Эмулятор файловой системы)
Простой графический эмулятор командной оболочки (shell), написанный на Python с использованием библиотеки `tkinter`. 
Описание:
Программа имитирует работу виртуальной файловой системы (VFS). Поддерживает базовые команды перемещения по директориям и вывода списка файлов. Интерфейс состоит из области вывода и строки ввода.
Возможности:
Интерактивный графический интерфейс на базе Tkinter.
Поддержка команд: ls — вывод списка файлов (заглушка). cd — переход в другую директорию (заглушка). exit — выход из эмулятора.
Корректный разбор аргументов командной строки с помощью shlex.
Требования:
Python 3.8 или выше. Tkinter (обычно идет в комплекте с Python).
